# Схема базы знаний ассортимента ПК "Канцлеръ"

## Описание
База знаний для агента "Пивной сомелье". Содержит информацию о 34 позициях ассортимента ПК "Канцлеръ" (пиво, пивные напитки, безалкогольные напитки).

> Примечание: в исходном ТЗ ожидалось 35 позиций; фактическое количество непустых строк
> в листе «Главное» исходного xlsx — 34. Расхождение зафиксировано, требует уточнения
> у владельца методички.

## Файлы
- Исходный: `МЕТОДИЧКА ПО АССОРТИМЕНТУ (1).xlsx` (НЕ коммитится в репозиторий)
- Нормализованный: `beer_kb_normalized.csv` (коммитится в репозиторий)
- Скрипт нормализации: `scripts/normalize_beer_kb.py`

## Категории

Определение категории (в порядке приоритета):

1. **Приоритетное правило:** если крепость <= 0.5 % об. — категория **безалкогольное**
   (независимо от стиля). Например, «ВИЦЕ КАНЦЛЕРЪ, безалкогольное пиво» имеет стиль
   «Светлый лагер», но относится к категории «безалкогольное».
2. Иначе — маппинг по стилю (см. ниже).

Маппинг по стилям:

- **лагер**: Светлый лагер, Темный лагер, Лагер, Пилснер, Келлербир, Чешский премиум-лагер, Пшеничный лагер
- **эль**: Пейл эль, Вишневый эль
- **пшеничное**: Вайсбир, Бельгийский витбир, Витбир, Лагер (Пшеничное пиво)
- **стаут**: Стаут, Русский Имперский стаут
- **портер**: Портер
- **пивной_напиток**: Пивной напиток (VIVA серия)
- **безалкогольное**: Квас, Лимонад, безалкогольное пиво (а также любая позиция с крепостью <= 0.5 %)

## Регламент обновления
- Частота: ~1 раз в месяц
- Ответственный: владелец проекта
- Процесс: обновить xlsx → запустить нормализацию (`python3 scripts/normalize_beer_kb.py beer_kb_source.xlsx beer_kb_normalized.csv`) → перезагрузить в Dify Knowledge Base

## Известные проблемы качества
- Количество позиций в исходном файле — 34 (вместо ожидаемых 35 по ТЗ).
- IBU отсутствует для части позиций (Вайлд Черри, VIVA серия, Белый Кролик, Чешская Корона, Вайцен, SVETLE, DESITKA, ДИПЛОМАТ, Хадыженское) — в чанках выводится как «не указано».
- Плотность отсутствует для кваса и лимонада.
- В строке «Овсяный стаут» в исходном xlsx пропущена ячейка крепости, из-за чего данные
  сдвинуты: скрипт автоматически переносит крепость (4.7 % об.) в нужную колонку;
  фильтрация для этой позиции в источнике потеряна — проставлено «не указано».
- Опечатки в исходном файле исправлены в нормализованной версии:
  - «элевые дрожи» → «элевые дрожжи»
  - «Русскиого имперского» / «Редкиого» → «Русского имперского» / «Русского»
    (фактический вариант опечатки в файле — «Русскиого»)
  - «гормоничная» → «гармоничная»
  - изолированное «пите» → «питкое»
  - «витбиров» → «витбир» (кроме корректного род. падежа мн. ч. «бельгийских витбиров»)
  - дополнительно: «чувствется» → «чувствуется», «на ряду» → «наряду»
